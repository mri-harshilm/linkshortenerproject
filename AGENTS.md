# Agent Instructions — Link Shortener Project

This project uses versions of Next.js, Tailwind CSS, Clerk, and other packages that contain **breaking changes** from what you may know. APIs, conventions, and file structure may differ from your training data.

> [!CAUTION]
> **MANDATORY — NO EXCEPTIONS:** You MUST use the `read_file` tool to fully read every relevant file in the `/docs` directory BEFORE writing a single line of code. Do NOT rely on memory, training data, or assumptions. Skipping this step WILL produce incorrect code. This is the most important rule in this file.

The following docs files MUST be read before generating any code in their respective domains:

- **Authentication:** [docs/auth.md](docs/auth.md) — read before ANY auth-related code
- **UI Components:** [docs/ui.md](docs/ui.md) — read before ANY component or styling code

## Non-Negotiable Rules

1. **Check the version.** Next.js 16, Tailwind v4, Clerk v7, React 19, and Drizzle 0.45 all have breaking changes. When in doubt, check `node_modules/next/dist/docs/` or the package's own docs.
2. **Default to Server Components.** Only add `"use client"` when strictly necessary.
3. **Use `cn()` for all class composition.** Never concatenate Tailwind classes with template literals.
4. **Scope all DB queries to the authenticated user.** Never return data that belongs to another user.
5. **Never hand-edit `components/ui/`** — those files are managed by the shadcn CLI.
6. **Never edit `drizzle/` migration files** — they are auto-generated by drizzle-kit.
